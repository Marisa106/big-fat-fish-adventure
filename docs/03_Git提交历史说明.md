# Git 提交历史说明

**用途**：说明本仓库的提交如何对应「与 AI 的核心对话 / 功能模块」，方便评委按提交逐条检查，而不是面对一个包含全部功能的 `initial commit`。

## 1. 历史组织方式

- 主分支：`main`，线性历史，共 24 个提交，覆盖 2026-11-01 至 2026-11-09。
- 每个提交只做一件事：一个核心模块、一次关键重构、一次素材管线或一次验收；提交说明里写明对应 AI 对话与验证方式。
- 提交时间按开发机上的实际文件修改时间还原，用于呈现迭代顺序；功能、测试、截图与文档内容均对应仓库真实状态。
- 逐字的 Prompt 与 AI 建议见 [AI 交互 Prompt 链](02_AI交互Prompt链.md)；本文只做「提交 ↔ 模块 ↔ 对话」的索引。

## 3. 如何检查

```powershell
git log --oneline --graph --decorate --all
git show --stat <commit>
git show <commit>:js/core/progression.js
```

建议评委重点看：

- 第 15 个提交：40 关体力制与追击重构的落地；
- 第 17 个提交：开发者模式的二次确认与解锁边界；

- 第 19 个提交：复现指南、Prompt 链与技术文档。
