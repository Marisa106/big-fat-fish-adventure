## 2. 30 秒验收路径（评委最省时间）

1. 双击 `index.html`，打开标题页；
2. 点「🛠 开发者模式」→ 出现二次确认；
3. 点「确认解锁全部 CG」→ 图鉴变为 **12/12**，自动打开；
4. 任选一个结局 → 播放剧照或成片；
5. 关闭图鉴 → 「开始冒险」→ 选职业 → 移动一步，确认棋盘、怪物、体力正常。

不需要联网，不需要安装 Node，不需要打一关。

## 4. 三次核心迭代（Prompt 链摘要）

| 迭代 | 初始 Prompt 要什么 | AI 第一次建议 | 真正的转折 | 结果 |
|---|---|---|---|---|
| 40 关体力追击 | 行动点制 → 体力制；怪物每次行动后追击；自动结算 | 保留行动点、击杀补刷、引入寻路库、拆 ES Module | 拒绝后要求「先复述约束」；Bug 阶段「先诊断再改」 | 3 个用户可见回归全部修复，119 测试 + E2E 通过 |
| 病例与 12 结局 | 三步病例、七维档案、12 结局、AI 可回退 | 让模型评分三步并直接决定结局、引入 SDK | 改为「本地判分 + AI 只评处方」；让 AI 写可达性矩阵 | 12 结局全部可达；AI 失败不卡关 |
| 精灵动画管线 | 37 帧、固定画布、脚底锚点、无白边/绿边 | 固定绿幕、按包围盒缩放、原生 24fps | 把「看起来不对」翻译成脚底 y、bbox、边缘像素比例 | 两套 37 帧图集；专项各 8 张截图；原图哈希未变 |

完整 Prompt 原文、AI 建议摘要、拒绝理由、Bug 诊断与修复命令见 [AI 交互 Prompt 链](02_AI交互Prompt链.md)。

## 6. 打包与提交建议

**应当包含**

- `index.html`、`css/`、`js/`、`assets/`（游戏本体与全部素材）
- `tests/`、`tools/`、`package.json`（可复现证据）
- `docs/`（本索引、复现指南、Prompt 链、技术文档）
- `README.md`、`.env.example`

**不要包含**

- `.env`（真实 Key；已在 `.gitignore` 中）
- `artifacts/chrome-profile/`（浏览器临时配置）
- 任何个人身份信息、API Key、录屏原始文件（除非比赛要求）

**打包前自检**

```powershell
npm test
npm run sim
# 可选：npm run screens
```
