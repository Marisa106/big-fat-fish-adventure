# 10 分钟极速复现指南

**项目**：《大肥鱼历险记 · DeepSeek 认知冒险》
**适用场景**：比赛评委现场验收、异地机器复现、录屏前环境自检
**目标**：在一台干净电脑上，**10 分钟内**完成「打开游戏 → 跑通核心玩法 → 验证 AI 接入 → 看到 12 结局 CG」的最小闭环；不包含重新生成美术素材。

---

## 0. 一句话版本

```powershell
# 无 API 的最短路径：解压后直接双击 index.html
# 需要 AI 点评时：
Copy-Item .env.example .env
notepad .env                 # 填入 DEEPSEEK_API_KEY
npm start                    # 打开 http://127.0.0.1:8123/
```

项目**没有 npm 运行时依赖**，不需要 `npm install`，没有构建步骤。

## 1. 环境与依赖清单

### 1.1 必需（运行游戏）

| 项目 | 最低要求 | 推荐 | 说明 |
|---|---|---|---|
| 操作系统 | Windows 10 / macOS 12 / 主流 Linux | Windows 11 | 本项目只在 Windows 11 + Chrome 157 上做过完整截图验收 |
| 浏览器 | 支持 ES2020、CSS Grid、WebP、WebAudio | Chrome / Edge 最新稳定版 | 不建议 IE、旧版 Safari |
| 磁盘 | 约 70 MB | 100 MB | 游戏素材 58.3 MB，代码与截图另计 |
| 内存 | 2 GB | 4 GB | 纯前端，占用很低 |
| 网络 | 离线可玩 | 仅 API 模式需要 | 离线模式 12 结局全部可解锁 |

### 1.2 可选（本地代理、自动化验证）

| 项目 | 最低要求 | 用途 | 不装的后果 |
|---|---|---|---|
| Node.js | 22+（推荐 LTS；仅代理运行 18+ 即可） | 本地静态服务器 + DeepSeek 代理、单元测试、平衡模拟、截图 E2E | 只能双击 `index.html` 玩离线模式；无法跑 `npm test` / `npm run sim` / `npm run screens` |
| npm | 随 Node 安装 | 执行 `package.json` 脚本 | 可直接用 `node tools/server.mjs` 等命令替代 |
| Chrome / Edge | 任意较新版本 | `npm run screens` 的真实视口截图与 E2E | 不影响游戏运行，只影响自动截图验收 |

### 1.3 仅重建美术素材时需要（普通复现不需要）

| 项目 | 版本 | 用途 |
|---|---|---|
| Python | 3.10+ | 运行 `tools/build_*_assets.py` |
| Pillow | 10+ | 抠图、缩放、图集拼接 |
| numpy | 1.24+ | 逐帧背景中位数、像素统计 |
| ffmpeg | 6+ | 从 mp4 抽帧、生成 H.264 成片 |

> 结论：**评委机器只需要浏览器；要跑测试再加 Node 22+；Python/ffmpeg 不装也完全不影响游戏与结局。**

### 1.4 依赖边界

- 运行时不加载任何 CDN、字体、第三方 JS；断网双击 `index.html` 可完整通关。
- `package.json` 没有 `dependencies` / `devDependencies`，因此不存在 `node_modules`。
- 本地代理只使用 Node 内置模块：`node:http`、`node:fs`、`node:path`、`node:url`。
- 测试只使用 Node 内置的 `node:test` 与 `node:assert`。

## 2. 环境变量模板

项目根目录提供 [`.env.example`](../.env.example)。复制为 `.env` 后填写即可；`tools/server.mjs` 会自动读取，**已存在的进程环境变量优先于 `.env`**。

```dotenv
# 必填：DeepSeek API Key（仅本地代理模式需要）
DEEPSEEK_API_KEY=

# 可选：模型名，默认 deepseek-chat
DEEPSEEK_MODEL=deepseek-chat

# 可选：API 基地址，默认 https://api.deepseek.com
DEEPSEEK_BASE_URL=https://api.deepseek.com

# 可选：本地服务端口，默认 8123
PORT=8123
```

| 变量 | 是否必填 | 默认值 | 敏感 | 说明 |
|---|---|---|---|---|
| `DEEPSEEK_API_KEY` | 仅代理模式 | 空 | 是 | 只存在服务器进程环境或本机 `.env`，不进入浏览器 |
| `DEEPSEEK_MODEL` | 否 | `deepseek-chat` | 否 | 也可在游戏「API 设置」中覆盖 |
| `DEEPSEEK_BASE_URL` | 否 | `https://api.deepseek.com` | 否 | 代理会拼接 `/chat/completions` |
| `PORT` | 否 | `8123` | 否 | 被占用时改这里 |

三种注入方式（任选其一）：

**PowerShell（当前窗口）**

```powershell
$env:DEEPSEEK_API_KEY = "sk-你的Key"
$env:DEEPSEEK_MODEL = "deepseek-chat"
npm start
```

**CMD（当前窗口）**

```bat
set DEEPSEEK_API_KEY=sk-你的Key
npm start
```

**`.env` 文件（推荐，重启后仍有效）**

```powershell
Copy-Item .env.example .env
notepad .env
npm start
```

> 安全：`.env` 已加入 `.gitignore`。不要把真实 Key 写进 `README`、截图、录屏或比赛压缩包；录屏前先确认标题页显示的是「AI：本地代理」而不是 Key 本身。

## 3. 方式 A：离线双击（约 2 分钟）

1. 解压比赛压缩包到任意目录（路径尽量不含空格与中文，避免个别浏览器对 `file://` 的限制）。
2. 双击 `index.html`，用 Chrome / Edge 打开。
3. 标题页应显示：`结局图鉴 (0/12)`、`AI：离线本地评分`，以及 `🛠 开发者模式` 按钮。
4. 点「开始冒险」→ 看剧情 → 选职业 → 应看到 9×9 棋盘、怪物、可移动高亮。
5. 点「🛠 开发者模式」→ 确认框 → 「确认解锁全部 CG」→ 应打开 12/12 结局图鉴。

**验收点**

- 没有网络也能进入游戏；
- 第 1 关开局有 2 只怪物，玩家周围有 1–4 个可移动格；
- 移动一次体力 -1，怪物会沿最短路靠近；
- 清空怪物后自动进入「回合结算」；
- 第 4 关出现第一个 AI 误解病例，可完成诊断 → 检查 → 处方。

> 若双击后白屏：优先改用方式 B；或在浏览器地址栏确认路径为 `file:///.../index.html`，并检查是否被安全软件拦截本地脚本。

## 4. 方式 B：本地代理 + DeepSeek（约 5 分钟）

### 4.1 启动

```powershell
Copy-Item .env.example .env
notepad .env          # 填入 DEEPSEEK_API_KEY
npm start
```

预期输出：

```text
大肥鱼历险记 · 本地服务
  游戏地址: http://127.0.0.1:8123/
  API 代理: http://127.0.0.1:8123/api/chat
  API Key : 已配置（sk-xxxxx…）
  模型    : deepseek-chat
```

### 4.2 健康检查

```powershell
Invoke-RestMethod http://127.0.0.1:8123/api/health
```

预期：

```json
{ "ok": true, "hasKey": true, "model": "deepseek-chat", "baseUrl": "https://api.deepseek.com" }
```

- `hasKey: false`：`.env` 没被读到，或启动前没有重启服务；
- 打不开：端口被占用，改 `PORT` 后重启。

### 4.3 游戏内接线

1. 打开 `http://127.0.0.1:8123/`（不要用 `file://`，否则 `/api/chat` 没有同源后端）。
2. 标题页 **⚙ API 设置** → 接入方式选「本地代理」→ 地址保持 `/api/chat` → 点「测试连接」→ 保存。
3. 标题页状态应变为 `AI：本地代理`。
4. 打到第 4 关，完成病例处方；反馈框应标注来源为 DeepSeek，而不是「本地评分」。
5. 若 API 失败，游戏不会中断：会 toast 提示并自动回退本地评分。

### 4.4 代理协议（便于二次开发）

`POST /api/chat`

```json
{
  "model": "deepseek-chat",
  "messages": [{ "role": "user", "content": "只回复两个字：OK" }],
  "temperature": 0.2,
  "max_tokens": 500,
  "stream": false
}
```

代理自动附加 `Authorization: Bearer $DEEPSEEK_API_KEY`，转发到 `${DEEPSEEK_BASE_URL}/chat/completions`，30 秒超时；无 Key 返回 503 并给出中文提示。

## 5. 方式 C：浏览器直连（不推荐，仅调试）

1. **⚙ API 设置** → 「直连 DeepSeek」；
2. Base URL 填 `https://api.deepseek.com`，模型 `deepseek-chat`，填 Key；
3. 保存后测试连接。

注意：

- Key 会存进浏览器 `localStorage`（键名 `bq.ai.settings`），不适合公用电脑；
- 浏览器直连可能被 CORS 拦截；失败会自动回退本地评分；
- 正式验收请用方式 B。

## 8. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `npm start` 报 `EADDRINUSE` | 8123 被占用 | 改 `.env` 的 `PORT`，或结束占用进程 |
| 打开页面但 `/api/health` 404 | 用了 `file://` 或别的静态服务器 | 必须用 `npm start` 启动的地址 |
| 健康检查 `hasKey:false` | `.env` 未创建 / 变量名拼错 / 没重启 | 检查 `.env`，重启 `npm start` |
| 代理返回 503 | 没配 Key | 配 Key，或切「离线」 |
| 代理返回 502 | 上游超时 / 网络 / Base URL 错 | 检查网络与 `DEEPSEEK_BASE_URL` |
| 直连报 CORS | 浏览器跨域限制 | 改用本地代理 |
| 测试连接成功但病例仍本地评分 | 设置未保存 / 模式不是代理 | 重新保存，确认标题页状态 |
| 视频不自动播放 | 浏览器自动播放策略 | 页面内点击后播放；代码已做静音兜底 |
| 结局图鉴是锁的 | 新浏览器未通关 | 用「开发者模式」或 `?unlock=all&screen=gallery` |
| `npm test` 报 `spawn EPERM` | 某些沙箱禁止子进程管道 | 请在普通终端运行；CI 与本地均使用 `node --test tests` 目录发现 |
| `npm run screens` 找不到 Chrome | 未安装或路径不同 | 安装 Chrome/Edge；或改 `tools/capture.mjs` 的候选路径 |
| 双击白屏 | 安全软件/浏览器限制本地脚本 | 用 `npm start`；或换 Chrome |

## 10. 复现边界（请提前告知评委）

- 本项目是**单机、单人、中文**游戏；不做联机、账号、局内存档。刷新即重开，只有结局解锁记录写入 `localStorage`。
- 首次进入没有结局解锁记录，图鉴显示 `0/12` 是正常状态；可用开发者模式一次解锁。
- AI 点评依赖外部 DeepSeek 服务；比赛现场网络不稳定时，离线本地评分可保证完整通关与 12 结局解锁。
- 美术素材已随包提供；`tools/build_*_assets.py` 只用于从原始立绘/视频重新生成，普通复现不需要 Python 与 ffmpeg。
- 4 段结局成片约 34 MB，首次播放会从本地磁盘加载；机械硬盘上可能有 1–2 秒首帧延迟。
